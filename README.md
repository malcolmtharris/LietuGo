# LietuGo

A simple Java console app to quiz myself on Lithuanian vocab. My girlfriend speaks Lithuanian so im trying to learn some. Since Lithuanian isn't a language option on Duolingo I figured I would just build something myself lol.

## What it does

- Pick a category to practice: Greetings, Food, Numbers, or Basic Words
- Gives you an English word, you type the Lithuanian transalation
- Shuffles the order every time you run it
- Keeps track on what you failed and quizzes you just on them at the end
- Shows your final score

## Running it

Maven project, open it in IntelliJ and run Main.java.
